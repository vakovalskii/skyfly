# ПОЛЁТ / skyfly

Браузерная игра: супергерой над Москвой и Петербургом, спутниковый рельеф,
здания OpenStreetMap, ходьба, прыжки, полёт и другие игроки через WebSocket.
Клиент — JavaScript + Three.js + Vite; сервер — Node.js + `ws`.

## Запуск

Нужен Node.js 22 LTS. Публичный репозиторий:
[vakovalskii/skyfly](https://github.com/vakovalskii/skyfly).

```sh
npm ci
npm run dev
```

Открыть `http://127.0.0.1:5174`, ввести имя и нажать кнопку старта.
Vite слушает локальный интерфейс; WebSocket использует порт `8791`.
Если серверы уже работают, использовать их, не запускать второй экземпляр.
Данные городов и модели уже находятся в `public/`; изображения и высоты
рельефа загружаются из интернета во время игры.

По умолчанию используются снимки и фасады. Для режима сетки открыть
`http://127.0.0.1:5174/?style=grid`. Клавиша `P` открывает редактор поз;
перед игровыми проверками закрыть его.

## Проверки

```sh
npm run build
```

Автотест `window.__test()` и папка `tests/` убраны по решению владельца (копия —
в `.cache/removed-tests/`, вне git). Проверка: детерминированные расчёты в Node
по `src/core/*` и ручной полёт; в dev-режиме есть `window.__fly` и панель `I`
(статистика отрисовки). Стиль по умолчанию — снимки и фасады, сетка — `?style=grid`,
прежнее небо — `?sky=old`, без теней — `?shadows=0`, пиксели — `?pr=1` (без него плотность
подстраивается под частоту кадров), облегчённые облака — `?clouds=low`, никогда не облегчать —
`?clouds=high`.

## Телефон

Палец по свободной части экрана вращает камеру. Кнопки допускают одновременное
удержание: «Вперёд» + «Форсаж», «Вверх» без движения вперёд для подъёма в зависании.
«Падать» отключает полёт; «Назад», «Стоп» и «Удар» доступны отдельными кнопками.
Короткие касания не теряются между кадрами. При уходе из браузера нажатия сбрасываются. Поддержаны портретная и альбомная
ориентации; помощь открывается кнопкой «?». В dev-режиме студия доступна через «Анимации».

На телефоне плотность рендера ограничена 1.25, облака автоматически облегчены,
подробные дома видны до 2.2 км, упрощённые до 9 км; самые мелкие тайлы z18 не
запрашиваются. ?pr= и ?clouds=high сохраняют ручное переопределение качества.

## Игра онлайн

[Открыть ПОЛЁТ](https://fly.neuraldeep.ru).

Студия доступна только в режиме разработки. В публичной сборке кнопки и код
редактора отсутствуют. Модель загружает `data/animations.json` самостоятельно;
сохранённые анимации применяются и к другим игрокам.

## Карта, сохранение и запись полёта

Кнопка города сверху переключает цель Москва / Санкт-Петербург. Цель не меняется
при пересечении середины маршрута. Нажатие на мини-карту переключает ближайшие
окрестности и весь маршрут; над городом на большой высоте подсказка предлагает снизиться.

При старте игра показывает этапы подключения, загрузки героя, городов и подготовки
места появления. Сервер сохраняет положение и режим движения для того же браузера.
Идентификатор находится в localStorage; после его очистки или на другом устройстве
начинается новая история. Это ещё не система аккаунтов.

«● Запись» записывает изображение игры и её звук; «■ Стоп» скачивает видео и оставляет
ссылку скачивания. Микрофон не нужен. Предпочтительный формат — MP4 H.264/AAC,
запасной — WebM, до 1920×1080 при 30 кадрах/с. Ограничение — 5 минут или около
200 МиБ. Выключенный в игре звук будет выключен и в записи. DOM-интерфейс и карта
в запись не входят; скорость и высота добавляются поверх видео.

Сохранения записываются сервером в `state/players.json` атомарно, каждые 5 секунд,
при отключении и штатном завершении. Для другого пути используется `SKYFLY_STATE_FILE`.
Файл содержит хэши идентификаторов браузеров и позиции; он исключён из Git.

## Мышь, игроки и обновления

Клик по игровому экрану или V включает управление мышью. Мышь выбирает направление,
W двигает героя по взгляду; Esc возвращает курсор. Подсказка снизу меняется при
включении мыши. На мини-карте зелёная стрелка — вы, розовые — другие игроки;
далёкие игроки отмечаются на краю. Изображения карты повторно загружаются при сбое,
до загрузки подробностей используются тайлы меньшего масштаба.

При новой версии появляется уведомление с кнопками «Обновить» и «Позже».
Игра не перезагружается сама; во время записи видео обновление просит сначала
остановить запись. Идентификатор сборки задаёт `SKYFLY_RELEASE`, а опубликованную
версию — `release.json`. Сервер дополнительно уведомляет уже открытые старые вкладки.

## Проверка ников

До входа и при смене имени сервер проверяет ник через OpenAI-совместимый API
(по умолчанию модель NeuralDeep `qwen3.6-35b-a3b-noreason`). В запрос уходит только
ник, без токена браузера, координат и чата. Запрещены мат, оскорбления, угрозы,
непристойности, экстремистские призывы и реклама; проверяются замаскированные варианты.
Неподходящий ник не попадает в список игроков или сообщения о входе.

Пример переменных — [.env.example](.env.example). Это **серверные** секреты;
префикс VITE_ использовать нельзя. Для локального сервера с заполненным `.env`:
`node --env-file=.env server.js` (клиент отдельно: `npx vite`). Без настроенного
API или при его недоступности можно войти с нейтральным именем вида «Герой123»
либо оставить поле пустым. Произвольный ник требует успешной проверки.

Есть кэш решений на сутки (до 1000 имён), объединение одинаковых запросов,
лимит 4 одновременных вызовов и 12 попыток входа в минуту на IP.
Старым открытым клиентам отклонённый ник заменяется на нейтральный при переподключении.
Ключ хранится только на сервере в переменных окружения. Используйте отдельный
ключ с ограничением модели, частоты запросов и бюджета. Чат этим модулем не
модерируется; аккаунтов и базы зарегистрированных ников пока нет.
