## Что уже есть в проекте

В hero-base.glb фактически 45 клипов: Idle, Walk, Jog, Sprint, Crouch,
Jump_Start/Loop/Land, Roll, Punch_Enter/Jab/Cross, Push, Sword, Interact и др.
Отдельного полёта в списке нет. Текущий flight-suite строит варианты позы
и небольшие синусоидальные циклы. Для выразительного действия нужны также
переходные позы, неравномерный темп, задержка конечностей и контакты с опорой.

Студия уже сохраняет полный скелет, наклон и смещение тела, позволяет менять
ключи и копировать позы. Самостоятельное авторство агентом возможно через
построение кадров на настоящем скелете и сохранение через локальный GET/PUT
с проверкой baseRevision. Черновики должны иметь новые ID, исходные клипы
остаются в библиотеке. Перед публикацией назначения сравнивать актуальную ревизию.

## Предлагаемый процесс

1. Выбрать действие и его характер: например, спокойное зависание или резкий разгон.
2. Сформировать 4–8 выразительных ключевых поз: подготовка, основной импульс,
   максимальное движение, компенсация, устойчивое положение.
3. Использовать IK-цели кистей/стоп и ориентацию таза/груди, сохраняя длины костей.
4. Настроить время фаз и кривые ускорения/замедления. Текущая интерполяция
   параметров линейная, вращения — quaternion slerp; управление easing
   между ключами ещё нужно добавить в схему, UI и проигрыватель.
5. Добавить запаздывание груди, рук и ног относительно таза, небольшую
   асимметрию и последующее успокоение. Не двигать всё одной синусоидой.
6. Зафиксировать стопы во время опоры. Для игры согласовать момент отрыва,
   касания и скорость шага с физикой; визуальный offset не двигает коллайдер.
7. Сформировать раскадровку с 2–3 ракурсов и короткое видео. Агент проверяет
   силуэт, перегибы суставов, скольжение стоп, пересечения и шов петли,
   затем исправляет ключи. Числовые проверки дополняют визуальную оценку.
8. Сохранить редактируемый вариант в animations.json. Движения, созданные
   процедурно, можно запекать в обычные кадры для дальнейшей ручной правки.

## Первая последовательность для игры

- Зависание: корпус устойчив, медленный подъём/спуск на несколько сантиметров,
  руки и ноги слегка компенсируют движение, без гребков.
- Зависание → полёт: взгляд/грудь задают направление, одна рука вытягивается,
  таз ускоряется, ноги догоняют; выход в авторскую позу.
- Полёт → форсаж: вторая рука выходит вперёд, ноги сближаются, тело выпрямляется.
- Торможение → зависание: грудь поднимается, ноги уходят вперёд/вниз,
  руки разводятся; небольшое движение по инерции и успокоение.
- Посадка: стопы касаются опоры, колени и таз принимают удар, корпус
  догоняет движение, затем выпрямляется. Разделить мягкую и сильную посадку.

Сначала довести переход «зависание → полёт → торможение → зависание» как
эталон качества, затем расширять библиотеку. Для одноразовых переходов
понадобится отдельная логика состояния/фазы; текущий crossfade сам по себе
не задаёт постановку такого движения.

## Внешние источники и способы использования

- Blender Pose Library: хранение именованных поз, применение к выбранным
  костям, смешивание поз. Подходит как образец отдельной библиотеки поз и
  масок частей тела для нашей студии.
  https://docs.blender.org/manual/en/4.2/animation/armatures/posing/editing/pose_library.html
- Blender Keyframes: кривые интерполяции и управление ускорением между ключами.
  https://docs.blender.org/manual/en/2.90/animation/keyframes/introduction.html
- Quaternius Universal Animation Library (120+) и Library 2 (130+):
  готовые движения, GLB/FBX, CC0. Часть пакетов бесплатна, исходники и полные
  наборы зависят от комплектации. Совместимость старого hero-base с новым
  universal rig проверена: 53 сопоставленные кости, 42 клипа, ошибка мировых
  позиций относительно источника менее 0,31 мм на проверенных отсчётах.
  https://quaternius.com/packs/universalanimationlibrary.html
  https://quaternius.com/packs/universalanimationlibrary2.html
- Three SkeletonUtils.retargetClip: перенос движения между скелетами с
  сопоставлением костей. API сверять с установленным three r170, текущая
  онлайн-документация может описывать более новую версию.
  https://threejs.org/docs/pages/module-SkeletonUtils.html
- Mixamo: подбор и настройка готовых клипов с последующим скачиванием.
  Это дополнительный источник, прямой перенос на наш скелет не проверен.
  https://helpx.adobe.com/nz/creative-cloud/help/animate-characters-mixamo.html
- DeepMotion SayMotion: генерация full-body движений по тексту, экспорт
  FBX/GLB/BVH/MP4. Можно использовать для черновиков с последующим переносом
  и ручной доводкой. Сервис в этой сессии не подключён и результат не тестировался.
  https://www.deepmotion.com/doc/saymotion

Blender не обнаружен в PATH и стандартном /Applications/Blender.app.
Первый этап можно выполнить существующими Three.js-инструментами; Blender
полезен как отдельная среда для сложных контактов, кривых и последующей доводки.
