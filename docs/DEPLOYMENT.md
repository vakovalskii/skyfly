# Развёртывание

Инструкция предназначена для разработчиков с разрешением правообладателя;
доступность исходников не отменяет [лицензию](../LICENSE).

1. Установите Node.js 22 LTS и выполните `npm ci`.
2. Настройте серверные переменные из `.env.example`. Настоящий `.env` не добавляйте
   в Git и не помещайте в каталог статики. Без LLM доступны нейтральные ники «Герой123».
3. Выберите идентификатор версии и соберите клиент, например
   `SKYFLY_RELEASE=my-release BASE=/ npm run build`.
4. Сборка сама создаёт `dist/release.json` с тем же идентификатором и объявлением.
   Текст задаётся переменной `RELEASE_MESSAGE` при сборке. Без `SKYFLY_RELEASE`
   каждая сборка получает новый идентификатор автоматически. Не перезаписывайте
   этот файл после сборки. В открытой игре объявление появляется при проверке
   версии (каждые 20 секунд), возвращении во вкладку или уведомлении сервера.
   «Позже» сворачивает его в кнопку; запись видео защищена от случайной перезагрузки.
5. Разместите содержимое `dist/` на своём HTTPS-сервере. Для `index.html` и
   `release.json` включите проверку свежести (`Cache-Control: no-cache`);
   хэшированные файлы `assets/` можно кэшировать надолго.
6. Запустите `node --env-file=.env server.js` под менеджером процессов.
   По умолчанию WebSocket слушает порт 8791, изменить его можно через `PORT`.
7. Проксируйте `/fly-ws` к серверу с WebSocket Upgrade. Локальный reverse proxy
   должен дописывать настоящий адрес последним в `X-Forwarded-For`
   (например, `$proxy_add_x_forwarded_for` в nginx); не доверяйте заголовку клиента.
8. Задайте `SKYFLY_STATE_FILE` для постоянного файла позиций вне каталога релизов
   и включите его в резервное копирование. Доступ к файлу — только владельцу процесса.
9. Задайте `SKYFLY_RELEASE_FILE` как абсолютный путь к опубликованному `release.json`,
   чтобы сервер уведомлял открытые игровые вкладки о новой версии.

Локальная разработка: `npm run dev`. Для своего LLM-ключа можно отдельно запустить
сервер указанной выше командой и клиент командой `npx vite`.

Смена релиза должна сохранять предыдущий каталог для отката и старые хэшированные
ассеты для открытых вкладок. Перед завершением проверьте HTTPS, загрузку модели,
анимаций и городов, подключение двух клиентов, восстановление позиции и запись видео.
Данные спутникового рельефа и карты загружаются из внешних сервисов и требуют сети.
