# Animation sources

`quaternius-ual2.json`: 42 motions retargeted from **Universal Animation Library 2,
Standard**, by Quaternius. CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/

Official source: https://quaternius.itch.io/universal-animation-library-2
Pack description: https://quaternius.com/packs/universalanimationlibrary2.html

Downloaded free Standard archive on 2026-09-29. Only `Unreal-Godot/UAL2_Standard.glb`
was converted; root-motion, FBX, mannequin and paid/source editions are not distributed.
The archive contains 43 clips; `A_TPose` is excluded. The JSON includes the source GLB SHA-256.

Conversion: `node tools/import-quaternius.mjs /path/to/UAL2_Standard.glb`.
Maps 53 bones, changes position units by 0.01, compensates the root's bind rotation,
retains in-place hip movement, removes redundant keys and scale noise.
The importer checks compatibility against `hero-base.glb` before writing.

The original hero model and its original 45 animations remain under their existing
CC-BY 3.0 attribution in `../models/LICENSES.md`.

Universal Animation Library 1 Standard was also inspected: its useful motions already
exist in our original model, so it is not duplicated here. No downloaded pack contains
a dedicated superhero flight cycle. The three `ready-*` flight cycles are generated by
Skyfly from the user's poses; they are not claimed to be downloaded mocap.
